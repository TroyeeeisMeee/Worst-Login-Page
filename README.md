# Worst Login Page
This is my take on the worst login page; it is annoying but not in an obnoxious way, creative but fun but will still make you feel like you're in hell whlie logging in.

## How to use
1. Register with a username and password (8+ chars, must include a number and a special character)
2. Click Log In
3. Pop the balloons spelling out your username, then your password — in order, no backspace
4. Submit and pray for your RNG, enjoy!

## Built with
HTML, CSS, JavaScript, Tailwind CSS
